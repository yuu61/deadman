# ログ

`-l DIR`（`--logging DIR`）を付けると、プローブの結果を 1 件 1 行で、監視する行ごとのファイルに追記します。
DIR が無ければ作ります。

## ファイル

DIR には次の 2 種類のファイルを置きます。

| ファイル | 内容 |
| --- | --- |
| `target-<識別子>.log` | 1 行分の結果。識別子は、[行の同一性](configuration.md#行の同一性)の SHA-256 の先頭 12 バイトを 16 進で表したもの |
| `targets.tsv` | どのログファイルがどの行のものか |

- ログファイルの名前は行の同一性だけで決まるため、表示名や認証情報を変えても同じファイルに書き続けます。同じ名前の行や、同じ監視経路の行が複数あっても、別のファイルになります。
- `targets.tsv` には `ファイル名<TAB>名前<TAB>アドレス` の行を追記します。追記するのは、起動後にその行を初めて記録したときと、名前かアドレスが変わったときです。同じファイル名の最後の行が、そのファイルの今の行です。名前やアドレスに含まれるタブと改行は空白に置き換えます。

## 行の形式

```text
2026-10-01 12:34:56.789012 up 1.234 1.180 42
```

空白で区切った 5 つの欄です。

| 欄 | 内容 |
| --- | --- |
| 日付と時刻 | 結果を記録したときのローカル時刻（マイクロ秒まで） |
| 状態 | `up`（応答あり）、`down`（応答なし。`X`）、`unknown`（観測できなかった。`t` / `s` / `?`） |
| RTT | このプローブの RTT（ms、小数 3 桁）。応答が無ければ `0.000` |
| AVG | その時点の AVG（ms、小数 3 桁） |
| SNT | その時点の SNT |

統計の意味は [画面の見方](display.md#列) と同じです。`r` で統計をリセットすると、AVG と SNT も 0 から数え直します。

## 書き込みの扱い

- 書き込みは監視とは別に行い、遅いファイルシステムでも監視を止めません。書き込みが追いつかずに溜まった行が上限（16384 行）を超えると、新しい行を捨てます。
- 捨てた行の件数と書き込みの失敗は、画面上部に警告し、終了時にもエラーとして表示して、終了コードを 1 にします。
- 終了時は、溜まっている行を最大 2 秒かけて書き出します。
- 部分的な書き込みや異常終了で残った未完成の末尾行は、次の追記の前に取り除きます。
- DIR を削除したり別のディレクトリに置き換えたり（ローテーション）した場合は、DIR を作り直して書き続けます。

## 旧版からの移行

- 旧版のログファイル名は表示名から作っていました。今の版は `target-<識別子>.log` に書くため、旧版から移ると、すべての行が新しいファイルに書き始めます。どのファイルがどの行のものかは `targets.tsv` で確かめてください。
